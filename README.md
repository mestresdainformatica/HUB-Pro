## O que ele faz

| | |
|---|---|
| 🚀 **Pós-formatação** | Tudo para depois de formatar, em ordem: ponto de restauração, Windows Update, ativação, remover os apps de propaganda, instalar seus programas **já em português** e deixar o Windows configurado. |
| 📦 **Programas** | Instale os programas mais usados com um clique (do site oficial de cada um) e mantenha todos atualizados. |
| 🩺 **Análise do PC** | Um clique dá uma nota de saúde de 0 a 100 e mostra o que precisa de atenção. |
| 🧹 **Limpeza** | Apaga arquivos temporários, caches e restos de atualizações — seus documentos, fotos e senhas nunca são tocados. |
| 🗑️ **Desinstalador** | Remove vários programas de uma vez e procura as sobras que ficam para trás. |
| ⚙️ **Otimizações** | Menos propaganda, menos rastreamento e um Windows mais rápido — tudo pode ser desfeito. |
| 🖥️ **Meu PC e Discos** | Peças do computador e saúde do HD/SSD. |
| 🔌 **Drivers** | Aparelhos sem driver, drivers pelo Windows Update e driver da placa de vídeo NVIDIA, AMD ou Intel pelo instalador oficial, com a assinatura conferida. |
| 🌐 **Rede** | Teste de internet que diz onde está o problema, com histórico e comparação. |
| 📊 **Benchmark** | Meça o desempenho e compare antes e depois de uma mudança. |
| ⏻ **Inicialização** | Veja o que abre junto com o Windows, com ícone e explicação de cada programa, e desligue o que não precisa. |
| 🌍 **Idiomas e tema** | Português do Brasil, português de Portugal, español e English. Abre no idioma e no tema do Windows; o tema troca na hora, com um clique. |

## Como baixar e instalar

1. Clique em **[Baixar o HUB Pro](https://github.com/mestresdainformatica/HUB-Pro/releases/latest)**.
2. Em **Assets**, baixe o **`HUB-Pro-Setup-...exe`** (instalador) — ou o `MestresHub.exe` se preferir a versão portátil, sem instalar.
3. Abra e siga o instalador. O HUB Pro pede permissão de administrador porque mexe nas configurações do Windows.

> **O Windows mostrou "O Windows protegeu o computador"?** Isso aparece em programas novos que ainda não têm assinatura digital paga. Clique em **Mais informações → Executar assim mesmo**. Baixe sempre **só por esta página** ou pelos links do canal.

**Atualizações:** o HUB Pro avisa sozinho quando sai uma versão nova e se atualiza em um clique — sem precisar voltar aqui.

## Segurança em primeiro lugar

- Cria um **ponto de restauração** antes de mudar qualquer coisa.
- Todo ajuste guarda o valor original e pode ser desfeito na **Central Desfazer**.
- **Nunca** desliga o Windows Defender, o Firewall, o UAC, o SmartScreen, o Windows Update ou a Microsoft Store.
- As atualizações do próprio HUB são conferidas (SHA-256) antes de instalar.

**Requisitos:** Windows 10 (1809 ou mais novo) ou Windows 11, 64 bits.
